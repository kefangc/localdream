# 项目导航与生成记录界面

## 入口与归属

- 左侧「项目」可展开/收起；项目行悬停或键盘聚焦时显示更多菜单与创作入口，触屏上直接显示操作。
- 更多菜单包含编辑、归档/恢复、移除。新建和编辑使用表单弹窗。
- 进入项目后，面包屑显示「项目名称 / 创作空间」，新普通任务、长视频计划与其片段、上传素材均保存该项目 ID。
- 左侧全局「创作空间」始终返回「我的工作室」，新创作不自动归属任何项目。不再显示顶部项目选择横条。
- 创作模式统一为文生视频、图生视频、首尾帧、多参考视频、长视频。自动判定策略仍保留在设置中，手动点选普通模式是明确覆盖自动判定。
- 项目创作只使用该项目的 @ 素材；全局素材库仍可管理所有素材。切换项目时普通提示词草稿按空间分别保留，长视频浏览器草稿按项目使用独立键。
- 归档项目可恢复；移除项目只隐藏项目，不删除素材、生成记录、MP4 或 latent 文件。既有无项目记录不会被猜测归入现有项目。

## 生成记录

- 统一 16:9 预览、状态标签、标题与日期、两行提示词摘要、参数和归属信息。
- 卡面保留「继续视频/重用描述」、下载与更多菜单；不再将所有操作和项目下拉框平铺在底部。
- 更多菜单提供完整参数与提示词、归档/恢复、删除及移动项目。完整任务 ID 位于详情弹窗。
- 归档记录进入「已归档」筛选，不占据默认记录和最近创作。
- 网格按可用宽度排列，操作按钮不拆字，菜单通过 portal 避开卡片裁切。

## 验证与部署

前端已执行 typecheck/build，并在隔离 8793 预览中验证项目入口、菜单、面包屑、记录归档及桌面/390px 布局。预览使用临时数据库；视频记录元数据为只读副本，播放请求只读转发，没有改动真实记录或提交推理。

后端关键测试覆盖：空项目列表、编辑/归档/恢复/移除且保留项目内容；普通任务和长视频片段的显式项目归属与默认不归属行为。测试不调用真实生成。

前端静态资源构建到 `frontend/dist`，刷新页面可加载新布局。新的项目归档/移除接口和项目归属保存逻辑需要重新启动 Go 后端才生效。本轮没有重启正式 Local Dream 或 ComfyUI，没有生成新视频。
