# 分阶段交付路线

## M1：一个真正可用的动态素材闭环

范围只覆盖 H3 多参考模式；其他已有模式先保持兼容。不是先实现所有模型或所有参数发现。

任务顺序：

1. 收尾 Catalog：有效离线配置、普通故障降级、调用者取消传播、未知模式拒绝。
2. 类型化读取当前模板所需的最小 manifest 信息，不同时迁移所有 LoRA/分辨率逻辑。
3. 增加能力查询 API，建议 `GET /api/workflows/capabilities?mode=multi_reference_video`；先定义 DTO，再接 Catalog。
4. 页面显示所选模式的图片/视频/独立音频限制、来源和不可用原因；数量来自本次选中素材。
5. 提交请求携带结构化素材绑定。服务端查元数据并在入队/复制前验证；前端禁用不是安全边界。
6. 将新规则接到当前编译器，统一验证来源，去掉被替代的硬编码。每个修改有回归测试。
7. 确认独立音频与视频音轨是否确实绑定；用用户选定的小样本完成真实运行。

验收：

- 假 ComfyUI 返回不同 max 时，API 结果随之改变；不写死 9/3/3。
- 超限 HTTP 请求被拒绝，未创建任务、未复制文件、未向 ComfyUI 提交。
- 离线页面可浏览并显示降级状态；不显示虚假的“执行端正常”。
- 同名文件不误绑定；首尾角色和独立音频不被提示词重写弄丢。
- 至少一次小规模真实生成有可播放输出、日志、参数与素材记录；高上限仅用模拟测试，不强迫 8GB 显存跑满所有槽位。
- 音频生成能力单独记录图结构验证与实际输出检查，不能只因任务返回 200 就称音频恢复成功。

止损：两次专注会话仍在扩大 Catalog 抽象时，停止增加新通用类型，先用一个模式完成 API 到页面链路。真实生成受环境阻塞时，保留模拟闭环成果，并明确未验收项，不能标记 M1 完成。

## M2：可靠任务与数据

学习 SQL 和并发，但按功能逐步迁移：素材元数据 -> 任务状态 -> worker -> 取消 -> 恢复。

- SQLite 表：assets、generations、generation_assets、schema_migrations；必要字段含版本、状态、prompt_id、时间和错误码。
- 持久唯一 ID，避免进程重启后 seq 覆盖旧素材。
- 媒体文件保存在磁盘。设计先临时写入、验证、入库与孤儿文件核对流程；数据库事务不能自动回滚文件系统。
- 单 worker、任务容量限制、受控背压；GPU 并发默认为 1。
- 区分本地 queued、已提交远端、running、cancelling、cancelled、completed、failed、需核对状态；不把远端提交成功直接当正在生成。
- 保存 prompt_id，排队删除与运行中断分别验证实际 ComfyUI API；共享 ComfyUI 上不可盲目调用全局 interrupt 取消他人任务。
- context 控制本地请求并不自动撤回远端任务；取消结果不确定时如实记录。
- 重启后查远端队列/history 核对，不直接重提未知提交，避免重复耗 GPU。

验收：服务重启数据保留；多个提交按预定顺序运行；取消不会被后续成功覆盖；提交成功但保存 prompt_id 前崩溃的边界有恢复策略；磁盘/DB 失败不会形成假成功。

## M3：可复现与小范围试用

- 逐一验证文生、图生、首尾帧，不假设相同节点类型代表相同产品能力。
- 保存提示词、seed、模式、模板版本/hash、模型/LoRA、素材绑定与运行配置。
- 作品访问与素材删除规则明确，日志能用 job_id/prompt_id 定位故障。
- 随功能拆分 asset、generation、httpapi，入口只组装依赖；不是机械按行数拆文件。
- 测试环境无用户媒体依赖，干净 checkout 能按说明构建。
- 提供配置示例、运行说明、常见故障与支持版本表；不分发未经确认许可证的模型。
- 请至少一位目标用户完成任务并记录卡点、失败原因和是否需要打开 ComfyUI 节点画布。

验收：他人能按文档启动并完成至少一个支持流程；参数可追溯；同配置可重复提交，但不承诺跨硬件逐像素一致。

## M4：有证据才扩展

候选项：更多模板、Agent 解释素材角色、语义 @ 标签、可视化模板导入、桌面打包、远程执行端。

进入条件：M1–M3 的阻塞项解决，且自用或试用证明某项扩展有价值。未知工作流先导入检查和人工确认，不让 LLM 自由修改执行图后直接运行。

## 工期与进度复盘

每个里程碑分为实现、自动验证、联调、真实使用四个状态。记录专注小时和阻塞原因，不把聊天轮数当工时。

完成两次会话后再估算剩余工作；如果学习某个主题超出预算，缩小交付范围或增加基础练习，不跳过测试谎称完成。全面“企业级平台”没有固定完成日期；上述三个里程碑是本计划的有限终点。
